Agent reference

Generator (1)

Calls base LLM. Output is treated as untrusted evidence, never the final answer.

Claim Extractor (2)

Breaks free text into structured JSON claims: type, entity, metric, value, unit, time period, safety flag.

Fact Verifier (3)

delta = |claim − evidence| / |evidence|. <1% → supported. 1–20% → soft conflict. >20% → contradicted.

Math Validator (4)

Deterministic numeric checks: unit groups, range plausibility, formula evaluation. Returns validity 0–1.

Verdict Engine (5)

BLOCKED if any claim blocked. FLAGGED on hard contradiction. APPROVED only if all claims supported.

Correction Agent

Rewrites contradicted spans using evidence text only. Triggered on FLAGGED verdict.

Reasoning Auditor

Asks LLM whether conclusion follows from evidence. Contributes a consistency score 0–1.

Confidence Vector

Six dimensions: source reliability, freshness, extraction quality, corroboration, math validity, semantic alignment.
